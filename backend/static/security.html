💡 Why this is secure

  • 🔐 Nobody can read or forge an alert. Each device shares a unique 256-bit secret with the server. Every message is encrypted with AES-256-GCM — an interceptor sees only noise, and changing even one bit breaks the authentication tag, so the server rejects it.
  • 🔁 Old messages can't be replayed. Every message carries a one-time random number (nonce). Send the same packet twice and the server recognizes the duplicate and blocks it — that's the replay attack, and it fails.
  • ⏱️ Messages expire in 60 seconds. An attacker can't record an alert today and replay it next week — stale timestamps are rejected.
  • 🌊 Flooding doesn't work. Each device may send at most 5 messages per minute. Anything beyond that is rejected until the window slides.
  • 📝 Nothing happens silently. Every request — accepted or rejected — lands in the audit log above with the exact check that decided it. If someone probes the system, you see it here.
